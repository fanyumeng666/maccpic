# ccp1d 程序结构与算法讲解（面试版，含完成状态）

配图 `doc/fig/program_flow.png`（`tools/draw_flow.py` 生成）。绿色 = 已完成并通过测试（M0、M1，2026-11-01），橙色 = 待完成（M2–M7），灰色 = 数据。
本文按流程图的顺序逐模块讲：它做什么、用什么算法、关键公式、为什么这样选、面试可能追问什么。最后是完成状态表和一页速答卡。

## 0. 三十秒版本

PIC-MCC 一步只做四件事，循环 512000 次：

1. **推粒子**（push）：用节点上的电场插值到粒子位置，蛙跳推进速度和位置；碰到电极的粒子删掉并记账。
2. **碰撞**（mcc，待做）：按零碰撞法让一小部分粒子（电子 1.6 %）和背景氦气碰一次，改速度、产生新粒子。
3. **沉积**（deposit）：把粒子电荷按线性权重分到网格节点，得到 ρ(x)。
4. **解场**（poisson）：由 ρ 解一维泊松方程得到 φ 和 E，左电极电势是 V₀sin(2πft)，右电极接地。

"粒子 → 网格 → 场 → 粒子"就是 Particle-In-Cell；"蒙特卡洛碰撞"是 MCC。所有诊断（history、时间平均剖面、能谱、x–t 图、能量平衡）挂在这四步之后，续算文件让长算例可以分段。

## 1. 启动：input、global、random、init

### input.f90（已完成）

- **做什么**：从 `ccp1d.in` 读 namelist `&ccp1d`（几何 L、nx；电压 V₀、f、双频项；气体 n_gas、T_gas；初值 n₀、T_e0、T_i0；nppc、steps_per_period、n_periods、n_avg、n_phase；种子；续算与分段参数；直方图范围）。检查合法性，算导出量：dx = L/nx，dt = 1/(f·steps_per_period)，权重 w = n₀L/N，maxnp = maxnp_factor × 初始每 rank 粒子数。
- **为什么 namelist 而不是编译期常数**：四个算例和收敛测试要换参数，不应重新编译；运行目录里保存着 `ccp1d.in`，和输出放一起，结果可追溯。
- **追问**："权重的单位为什么是 m⁻²？" 一维模型里只有 x 方向有尺度，密度 n [m⁻³] 乘长度才守恒，一个宏粒子代表单位电极面积上 w 个真实粒子。

### global.f90（已完成）

- **数据结构**：粒子用"数组的结构"（SoA）：`x(maxnp,2), vx, vy, vz`，第二维是物种（1 电子，2 He⁺），`np(2)` 是在用的槽数。连续内存 → 推进循环可向量化、缓存友好。
- **删除粒子**：把最后一个粒子搬到被删的槽，`np = np − 1`，O(1)，顺序无关（PIC 不关心粒子顺序）。**新增**：追加到末尾；超过 maxnp 就 `MPI_ABORT`（所有进程一起退出，避免一个进程停了另一个在 `MPI_ALLREDUCE` 里死等——em2 就吃过这个亏）。
- **为什么每个进程持有整个网格**：nx + 1 = 129 个节点太小，不值得做区域分解；按粒子分解，每步只需一次 `MPI_ALLREDUCE`（129 个 double）。电离和壁面损失是随机的，负载自然均衡。
- **常数**：CODATA 2018；He⁺ 质量 6.67×10⁻²⁷ kg 按 Turner 原文。

### random.f90（已完成）

- **算法**：`ran2`（Numerical Recipes）：两个线性同余生成器（L'Ecuyer 组合，模数 2147483563 和 2147483399）相减，再过一个 32 格的 Bays–Durham 洗牌表打乱顺序。周期约 2×10¹⁸，和 em2 的 `dran2` 算法相同。
- **改动**：状态放进模块变量，提供 `rng_get_state / rng_set_state`，续算文件存下 35 个整数就能逐位接上（测试 T8 验证）。每个 MPI 进程用 `seed + rank` 初始化，序列不同。
- **高斯数**：Box–Muller，g = sqrt(−2 ln u₁)·cos(2πu₂)，不缓存第二个数（否则状态不完整）。`make check-rng` 用 2×10⁷ 个粒子和 1000 个种子验证了尾巴对称、各阶矩和自相关（见 `initial_conditions.md`）。
- **追问**："为什么不用 OpenMP？" ran2 有内部状态，多线程调用会竞争；这个代码只用 MPI。

### init.f90（已完成）

- **装载**：每个粒子依次抽 7 个均匀数：x = L·U，v_x, v_y, v_z = σ_v × 高斯，σ_v = sqrt(kT/m)。电子 30000 K，离子 300 K，均匀密度 n₀，两种粒子数相同（准中性）。
- **t = 0 的场**：先沉积 ρ(0)，解 φ(0)（V(0) = 0），再把速度回推半步 v(−dt/2) = v(0) − (q/m)E_p·dt/2，这是蛙跳格式的起步条件。
- **可选**：`dump_initial = .true.` 输出 t = 0 的粒子和网格量（`plot_initial.py` 用它画初始条件图）。
- **追问**："随机装载的噪声有多大？" 密度 1/sqrt(nppc) ≈ 4 %；电势的长波分量被泊松方程放大，rms 约 6 V；几个 ωpe⁻¹ 内被抹平。

## 2. 时间循环：push、mcc、deposit、poisson、diag

### 时间层（蛙跳 leapfrog）

| 量 | 时刻 |
| --- | --- |
| x, ρ, φ, E | 整数步 tₙ |
| v | 半整数步 tₙ₋₁/₂ |

一步：v^{n+1/2} = v^{n−1/2} + (q/m)E^n(x^n)dt；x^{n+1} = x^n + v^{n+1/2}dt；然后 ρ^{n+1} → φ^{n+1}（左边界用 V(t_{n+1})）→ E^{n+1}。

为什么是蛙跳：二阶精度、时间可逆、辛（相空间体积守恒），能量没有长期漂移；对频率 ω 的简谐运动稳定条件 ω·dt < 2，数值频率 ω_num = (2/dt)·asin(ω·dt/2) ≈ ω[1 + (ωdt)²/24]。Case 1 的 ωpe·dt = 0.12–0.17，Langmuir 振荡测试（T10）实测与这个公式差 3×10⁻⁴。

### push.f90（已完成）

- **插值**：E_p = E_j(1−s) + E_{j+1}·s，j = ⌊x/dx⌋，s = x/dx − j。先把节点场乘上 (q/m)dt，粒子循环里只剩一次插值和两次加法。
- **边界**：x < 0 或 x ≥ L 的粒子被电极吸收：记录 ½m(v_x²+v_y²+v_z²)、物种、哪一侧，送进缓冲区给 diag 做直方图，然后 O(1) 删除。不假设"一步一格"（450 eV 电子一步走 4.4 个格）。v_y、v_z 没有磁场，推进时不变——无碰撞时 T_⊥ 必须严格不变，T11 用这一点做检验。
- **三个精确累加量**：
  - 做功 Σ q E_p·½(v⁻+v⁺)·dt。因为 ½m(v⁺² − v⁻²) = ½m(v⁺−v⁻)(v⁺+v⁻) = qE_p dt·½(v⁺+v⁻)，它**恒等于**动能增量，所以能量记账可以闭合到舍入误差（`closure_relative` 10⁻¹⁶–10⁻¹¹）。
  - Shockley–Ramo 电流 Σ q v_x：一维平行板里，运动电荷在外电路感应的电流密度是 (w/L)Σ q v_x，加上真空位移电流 (ε₀/L)dV/dt 就是电源看到的电流。P_VI = ⟨V·I⟩ 是"电源输入功率"，不依赖网格。
  - 壁面动能通量（分物种、分侧）。

### mcc.f90 与 xsec.f90（已完成，M2）

**截面（xsec）**：6 张表（电子弹性、激发 19.82、激发 20.61、电离 24.59 eV；He⁺ 各向同性、背向散射），插值到均匀能量网格（电子 Δε = 0.01 eV 从 0 起，离子 Δε = 0.001 eV 从表的首点 1e-4 eV 起，网格点与表的节点重合，所以查表就是原表的分段线性函数，O(1)）；超出表范围取末值。启动时在 0–1000 eV（可调）上算 ν_max = max_ε n_g σ_tot(ε) v(ε)：电子 8.65×10⁷ s⁻¹（8.2 eV），离子 2.79×10⁷ s⁻¹（在能量上限处，用 ε_rel 和 g）。

**零碰撞法（null-collision，Skullerud 1968；Vahedi & Surendra 1995）**：

1. 把每个粒子的总碰撞频率人为补到同一个常数 ν_max（补上的部分叫"空碰撞"，什么都不做）。这样自由飞行时间是能量无关的指数分布，每步每个粒子碰撞的概率是 P = 1 − e^(−ν_max dt)，电子 1.6 %，离子 0.5 %。
2. 只对抽中的 1.6 % 粒子算当前能量的各过程频率 ν_k = n_g σ_k(ε) v。抽 R₂·ν_max，落在 [0, ν₁) 发生过程 1，[ν₁, ν₁+ν₂) 过程 2……落在 Σν_k 以外是空碰撞。
3. 代价 O(N·P) 而不是 O(N)，并且严格等价于逐粒子按真实频率抽样。一步最多一次碰撞带来 ν_max dt/2 ≈ 0.8 % 的频率偏低，测试 T5 的期望值里要乘 (1−e^(−ν_max dt))/(ν_max dt) = 0.992。
4. **守卫**：若某粒子的 Σν_k > ν_max（能量超出搜索上限），计数并写进 info.txt。

**电子碰后速度**（基准规定全部各向同性）：直接在球面上均匀抽新方向，cosχ = 1 − 2R，φ = 2πR'，不需要相对入射方向旋转。

- 弹性：ε' = ε[1 − (2m_e/M)(1 − cosχ)]，χ 是新旧方向夹角——质心系弹性碰撞的运动学在 m ≪ M 时的结果；平均每次损失 2m_e/M = 2.7×10⁻⁴ 的能量，是 19.8 eV 以下唯一的能量损失渠道。
- 激发：ε' = ε − ε_th。
- 电离：剩余能量 (ε − 24.59 eV) 两个电子**严格平分**（基准规定），各自独立抽方向；新离子放在父电子位置，速度从 T_g 的 Maxwell 分布抽（σ_v = 788 m/s），权重同为 w。

**离子碰后速度**（质心系）：抽靶原子 v_n（三个高斯分量，σ_v = 788 m/s）；g = v_i − v_n；ε_rel = ½μg²，μ = M/2；v_cm = (v_i + v_n)/2。各向同性：v_i' = v_cm + ½|g|·n̂（|g| 不变，能量在质心系守恒）。背向：n̂ = −ĝ，代入得 v_i' = v_n——离子换成了中性原子的速度，这正是共振电荷交换的效果，一行代码。

**能量账本**：每次碰撞记下阈值能量（非弹性）、弹性损失 Δε、新离子带进来的热能，窗口结束时和 P_part 一起闭合。

**追问**："为什么截面用 ε_rel 不用实验室能量？" Phelps 的 He⁺–He 截面定义在质心系；两个等质量粒子相撞，ε_rel = ε_lab/2（靶静止时）。"ν_max 为什么要能量上限？" 离子的 σ·g 随能量单调增，没有上限 ν_max 发散；上限 1000 eV 远高于 Case 1 可能的离子能量（≤ V₀/2 = 225 eV in ε_rel）。

### deposit.f90（已完成）

- **CIC / 线性权重**：形函数 S(x − x_j) = 1 − |x − x_j|/dx（|x − x_j| < dx）。粒子给节点 j 贡献 qw(1−s)/dx，给 j+1 贡献 qw·s/dx，单位 C/m³。Σ_j ρ_j dx = Σ qw 精确（电荷守恒，T2 验证到 10⁻¹⁶）。
- **为什么沉积和插值用同一个形函数**：这样粒子对自己产生的场的作用力为零（无自力），系统动量守恒——"动量守恒格式"。代价是能量不严格守恒（T11 测到 5×10⁻⁴ 的漂移，可接受）。
- **端点**：节点 0 和 nx 只覆盖半个格，密度输出乘 2；它们不进泊松方程（电势固定）。
- **MPI**：每个进程沉积自己的粒子，`MPI_ALLREDUCE(MPI_IN_PLACE, rho, nx+1, …)` 求和，所有进程得到完整的 ρ。窗口内的矩（n_e、n_i、n v_x、能量密度、x 方向能量密度）只在 rank 本地累加，窗口结束时归约一次。

### poisson.f90（已完成）

- **方程**：(φ_{j−1} − 2φ_j + φ_{j+1})/dx² = −ρ_j/ε₀，j = 1..nx−1；Dirichlet 边界 φ₀ = V(t)，φ_nx = 0。
- **Thomas 算法**：三对角系统 O(nx)。系数每步相同，前扫的修正系数 c'_j、1/(b − a c'_{j−1}) 在 `poisson_init` 预存，每步只做右端的前扫和回代。
- **场**：E_j = −(φ_{j+1} − φ_{j−1})/(2dx)，两端二阶单侧差分 E₀ = −(−3φ₀ + 4φ₁ − φ₂)/(2dx)。面场 E_{j+1/2} = −(φ_{j+1} − φ_j)/dx 满足**精确的离散高斯定律** ε₀(E_{nx−1/2} − E_{1/2}) = Σ_{j=1}^{nx−1} ρ_j dx，diag 每步检查它（残差 10⁻¹³）；场能 W = ½ε₀Σ E_{j+1/2}² dx 与 ½Σρφ dx 在接地时严格相等。
- **追问**："为什么不用 FFT？" 有界非周期，Dirichlet 边界；三对角解法本来就是 O(nx)，比 FFT 还便宜。"em2 的泊松求解为什么不能搬？" 它是周期二维的共轭梯度修正，边界完全不同。

### diag.f90（已完成）

- **history.dat**（每周期一行，31 列）：粒子数、平均与中心密度、左右离子/电子通量、平均撞击能、P_e、P_i、P_VI、动能、场能、累计壁面能量、累计做功、高斯残差、墙钟、T_x/T_⊥。用它判断稳态（粒子数和中心密度走平）和能量守恒。
- **测量窗口**（最后 n_avg 个周期）：时间平均剖面、壁面能谱（IEDF：通量能量分布 [m⁻² s⁻¹ eV⁻¹]，撞墙宏粒子计数 × w/(Δε·T_win)）、EEPF（中心 10 % 的 F(ε)/√ε，Maxwell 在半对数图上是直线，斜率 −1/T_e）、x–t 图（周期切成 n_phase 个相位格，每格平均 n_e、n_i、J_e、J_i、φ、J_e·E、电离率）。
- **能量平衡三把尺**（写在 info.txt）：P_part（精确做功，收支必须闭合到舍入误差，查记账）；P_JE = ∫⟨J·E⟩dx（网格量，查沉积/插值的一致性）；P_VI = ⟨V·I⟩（电源输入，查对外的功率）。P_VI − dW/dt − P_part 是格式的能量误差（Case 1 全尺寸 0.5 %）。Case 1 里网格乘积 ⟨J_e·E⟩ 只有电子做功的 54 %：电子一步跨几个格，J 在新位置、E 在旧位置，乘积的中心化不一致；所以加热剖面用逐粒子做功按旧位置沉积（`P_work_e`），它的积分精确等于 P_part，⟨J·E⟩ 只作对照。这是个好的面试例子："看起来合理"的网格诊断可以差一倍。定量验证：差额集中在鞘层边缘（两侧鞘层精确 12.3/11.4 W/m²，网格 5.4/4.4），dt 减半后比值 0.536 → 0.773（亏空正好减半），dx 减半不变（0.532）——是电子一步走 v·dt（3–100 eV 电子 0.4–2 格）与力作用地点错位的一阶 dt 误差，与网格无关。静电 PIC 没有 Courant 条件，这种"一步跨格"不影响稳定性，密度剖面也不敏感（T15），只有乘积型的网格诊断会失真。
- **续算**：`restart_rankNNN.bin`（本 rank 的粒子、随机数状态、粒子类累加器）+ `restart_grid.bin`（φ、E、步数、时间、网格类累加器）。粒子类累加器是 rank 本地和、结束时归约；网格类在所有 rank 上相同、不归约——这个划分使续算逐位可复现（T8）。
- **追问**："为什么 x–t 图能看到随机加热？" 电子加热的 x–t 图（精确做功沉积）显示能量在鞘层边缘摆动的位置和时刻注入电子；欧姆加热则均匀分布在体区。Case 1 的鞘层边缘在 0.26–2.72 cm 间摆动，相位平均的加热峰在 2.20 cm，正落在摆幅之内。
- **总电流检验**：J_e + J_i + ε₀∂E/∂t 在一维里必须处处相同（连续性方程 + 高斯定律的推论），用 x–t 图算出来沿 x 的 rms 变化只有振幅的 1.7 %，这一个数同时检验了沉积、场解、相位分格三件事。鞘层里以位移电流为主，体区以传导电流为主，两者之和才守恒——这也是容性放电"电容性"的来源。

### main.f90（已完成）

每个周期：`diag_window_check` → steps_per_period 次 {push ×2 → (mcc) → deposit → poisson(V(t_{n+1})) → diag_step} → `diag_period` → 续算文件 / 停止判断。停止条件三选一：周期数到、`periods_this_run` 到、`max_wall_minutes` 到（后两者写续算文件后干净退出，下次 `restart = .true.` 接上）。`n_gas > 0` 时目前打印警告并以无碰撞方式运行（M2 完成后接入 `mcc_step`）。

## 5. 面试速答卡

1. **PIC 的基本循环？** 粒子推进 → 电荷沉积到网格 → 解场方程 → 场插值回粒子。网格只是解场的工具，物理在粒子上。
2. **为什么用 CIC 而不是最近格点 NGP？** NGP 的密度在粒子跨格时跳变，噪声大、有强网格加热；CIC 一阶连续，噪声小得多，且沉积/插值同形函数保证无自力。
3. **时间步长怎么定？** 三个条件：ωpe·dt ≲ 0.2（电子振荡）；v_th·dt < dx 不是硬条件但要合理（0.24）；ν_max·dt ≪ 1（碰撞，1.6 %）。Case 1 取 400 步/周期满足全部。
4. **网格怎么定？** λ_D/dx ≳ 0.3 避免有限网格不稳定性（数值加热）；Case 1 初始 1.43，稳态约 1.9。
5. **每格粒子数怎么定？** 噪声 ∝ 1/sqrt(N)；稳态中心每格约 280，瞬时 6 %，时间平均后 < 1 %。粒子太少 → 场噪声 → 数值加热。
6. **蛙跳为什么好？** 二阶、时间可逆、辛，能量无长期漂移；代价是 v 和 x 差半步，起步要回推、能量诊断要注意时间层。
7. **零碰撞法的复杂度和正确性？** O(N·P) 而非 O(N)；把总频率补到常数 ν_max，自由飞行时间与能量无关，被补上的"空碰撞"不改变状态，所以严格等价。
8. **电离后能量怎么分？** 基准规定平分；真实物理是按微分截面（如 Opal 分布），平分是基准为了可比性做的简化。
9. **离子的电荷交换怎么处理？** 作为背向散射：质心系反向 → v_i' = v_n，离子带着中性原子的热速度继续，这就是 IEDF 低能部分的来源。
10. **为什么 1d3v？** 碰撞和能量需要三维速度；无磁场所以 v_y、v_z 只在碰撞中变。
11. **MPI 怎么分？扩展性？** 粒子均分，网格全复制，每步一次 129 个 double 的 ALLREDUCE。粒子数 ~10⁵ 时 2–16 核线性，更多核后集合通信时间占比上升；Case 2–4 粒子和步数都更多，更适合多核。
12. **怎么证明代码是对的？** 分层：解析解单元测试（泊松、沉积、随机数）→ 守恒律（能量、高斯定律、电荷、T_⊥）→ 标定（Langmuir 频率、鞘层通量平衡、swarm 参数）→ 基准（Turner Case 1：中心 +2.1 %，129 点 rms 1.5 %）→ 收敛（dt/2、dx/2、粒子数 ×2 的变化 ≤ 2 倍换种子的噪声，噪声地板 1.4 %）。
17. **质量比用多少？** M/m_e = 7322（Turner 规定 M = 6.67×10⁻²⁷ kg，真实 He⁺ 为 7296）。一维静电不需要像 em2 那样压缩到 100：离子渡越 4.3 µs 远小于模拟的 94 µs，真实质量比可以直接算。
19. **双频为什么能分开控制离子能量和密度？在这里为什么不完全行？** 高频决定电子加热和密度，低频（离子能跟上）决定鞘层电压和离子能量。Case 1 加 1.356 MHz 后 E_max 从 240 升到 298 eV 并保持 ≈ 0.5(V₀+V_lf)，但密度掉了一半：低频把鞘层撑厚（s ∝ V^{3/4}），6.7 cm 的间隙里体区被挤小，200 V 时两侧鞘层相遇、放电熄灭。工业反应器间隙 2–3 cm 但密度高一个量级，鞘层只有毫米级，所以解耦才成立。
18. **静电 PIC 有 Courant 条件吗？** 没有，泊松方程是瞬时的。约束是 ω_pe·dt 和 λ_D/dx；电子一步跨格只影响精度，Case 1 的 30 eV 以上电子一步跨 1–4 格，密度剖面仍收敛。电磁 PIC（em2）则必须 c·dt < dx。
13. **能量平衡怎么查？** 三把尺：逐粒子做功（恒等式，查记账）、∫J·E（查网格）、⟨V·I⟩ Ramo 电流（查对外功率）；三者之差是数值误差。
14. **续算怎么做到逐位一致？** 存粒子、随机数状态、所有累加器；进程数固定；归约顺序固定。
15. **Turner 基准是什么？** 2013 年五个独立 PIC-MCC 代码对同一组氦容性放电参数的对比，Case 1 是 450 V、13.56 MHz、6.7 cm、30 mTorr，结果是时间平均离子密度剖面，五个代码之间差 < 1 %。
16. **无碰撞时发生了什么（M1 的发现）？** 电子 x 方向温度塌缩（逃逸带走 v_x 能量，没有机制从 v_⊥ 补充），浮动电势只有 0.2 V；这说明碰撞和射频加热对维持放电的作用。
